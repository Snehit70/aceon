# Aceon

This context defines the core learning objects in Aceon, a lecture library and progress-tracking workspace for IITM BS students.

## Language

**Course**:
The top-level academic unit a student follows in the library.
_Avoid_: subject, class

**Week**:
A course subdivision that groups lectures and progress into a teaching block.
_Avoid_: module, chapter

**Lecture**:
A single watchable lesson inside a course week.
_Avoid_: video, clip

**Enrolled Course**:
A course the student is actively taking and should see in the main working set.
_Avoid_: active class, current subject

**Archive**:
A library area for courses that are available for reference but not part of the active enrolled set.
_Avoid_: backlog, old courses
